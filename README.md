## 只下载 exe 怎么用

1. 打开 [Releases](https://github.com/GUOKAISHUAISHUAI123/koufengqin-simulator/releases/latest)，下载 `kouqin-simulator.exe`。
2. 放到任意文件夹，双击即可。第一次可能被 Windows SmartScreen 拦截，选「仍要运行」。
3. 打开后自带 12 首（默认《成都》），不用再导入也能练。
4. **代按前**：右键 exe →「以管理员身份运行」；游戏开无边框。点代按会再弹一次确认。

导入或改过的曲子会自动保存在本机，**下次打开还在**，不用每次重新导入。

| 保存位置 | 路径 |
|---|---|
| 主目录（换文件夹、重下 exe 也还在） | `%AppData%\koufengqin-simulator` |
| 备用（exe 旁边） | `koufengqin-data` |

不要删这两个目录。换电脑时把该文件夹拷走，或在软件里「导出曲库」。

## 键位

| 音 | 键 |
|---|---|
| 中音 1–7 | `Z X C V B N M` |
| 高音 1 | `,` |
| 高音 | 按住鼠标右键 + 音键 |
| 低音 | 按住鼠标左键 + 音键 |
| 半音 | 按住鼠标中键 |

同时要升降八度又要半音时，保八度、丢半音。谱里和弦只取第一个音。

## 练习 / 代按

- **练习**：透明跟谱，按对才往下走，只校验音键，不必点悬浮窗。
- **代按**：3 秒倒计时后按谱自动模拟键鼠（NPC 节奏，结束会按 Q）。
- `/` 或 `?` 暂停/继续，`F9`（或 `F8`）停止并松开全部键鼠。
- 游戏里要先自己掏出口琴，再开始代按。

## 曲库导入 / 导出

软件里可导入、编辑、导出。导出格式：

```json
{"app":"口风琴模拟","version":1,"library":[{"id":"...","title":"...","events":[{"t":0,"d":0.3,"key":"z","note":"1","mouse":[]}]}]}
```
