# 口琴模拟器

浏览器里就能练的口琴模拟，也可用 Electron 做透明跟谱和自动模拟键鼠弹奏。

本工具免费开源，只做编程学习交流。

## 直接用

- **Windows 下载 exe**：打开 [Releases](https://github.com/GUOKAISHUAISHUAI123/koufengqin-simulator/releases/latest) 下载 `kouqin-simulator.exe`（就是口琴模拟器，约 80MB），双击即可。若目标窗口本身是管理员运行，再右键 exe 选「以管理员身份运行」。
- **开发**：`npm install` 后 `npm start`。
- **只看界面**：用浏览器打开 `index.html`（跟谱悬浮窗和代按必须走 Electron）。
- 自己重新打包：`npm run pack:win`。

打开后默认选中《成都》。曲库已自带 12 首（成都、离人赋、歌唱祖国、金玉良缘等），不用再导入。

## 键位

| 音 | 键 |
|---|---|
| 中音 1–7 | `Z X C V B N M` |
| 高音 1 | `,` |
| 高音 | 按住鼠标右键 + 音键 |
| 低音 | 按住鼠标左键 + 音键 |
| 半音 | 按住鼠标中键 |

同时要升降八度又要半音时，保八度、丢半音。谱里和弦只取第一个音。

## 练习 / 代按

- **练习**：透明跟谱按对才前进，只校验音键，不必点悬浮窗。
- **代按**：倒计时结束后按谱自动模拟键鼠弹奏（NPC 节奏，结束会按 Q）。`/` 或 `?` 暂停/继续，`F9` 停止并松开全部键鼠。
- 目标窗口若以管理员运行，本工具也要用管理员开，否则按键会被系统丢掉。
- 规律按键可能被安全软件判异常。不要用于竞技场合。

## 曲库

运行时曲库在 `library/imported-songs.js`，也可在软件里导入/导出 JSON。导出格式：

```json
{"app":"口风琴模拟","version":1,"library":[{"id":"...","title":"...","events":[{"t":0,"d":0.3,"key":"z","note":"1","mouse":[]}]}]}
```

继续改代码前请先读 [AGENTS.md](./AGENTS.md)。
